1
Ouvrez les paramètres de Claude, rubrique Connecteurs.

Ajoutez un connecteur personnalisé et collez l’adresse du serveur.

Dans une conversation, activez « Obiou Sommets » puis posez votre question.
Dans Claude Code
claude mcp add --transport http obiou-sommets https://sommets.obiou.eu/mcp

Vous éditez le site ?
Un accès séparé, authentifié, permet de préparer des brouillons avec votre assistant. Il ne peut ni publier ni supprimer.
